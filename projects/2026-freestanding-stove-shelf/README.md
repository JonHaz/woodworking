# 2026 — Freestanding Rear Stove Shelf

**Status:** planning
**Started:** 2026-07-21

## Goal
A premium freestanding over-stove shelf in red oak: a shelf that rests on two
side legs and bridges the gap behind a 30" range, stopping items from falling
behind it and adding storage for cooking staples. It uses **no wall or counter
fasteners** and **no visible screws** (concealed dowel joinery, glue only), so
it lifts off in seconds when the range needs to move. Redesigned from an Etsy
reference to be stronger and more furniture-like: a two-board edge-glued top,
a hidden floating-top reveal, and a raised rear fence.

## Structure
- `design/` — dimensioned spec (markdown), revisions numbered, plus the

- `guides/` — print-ready HTML: one self-contained master build doc
