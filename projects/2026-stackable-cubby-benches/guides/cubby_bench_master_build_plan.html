BASE 2×4 (Phase 1): use the eight on-hand 54-1/8 in offcuts first — each cuts into one 33-in rail + one 11-in rung (8 + 8). Three new 8-ft sticks finish the set: two cut 33+33+11+11, one cut into six 11-in rungs → 12 rails + 18 rungs total.
CUTTING (Fig. 1, S1–S4): rip each of sheets 1–3 into two 17-in strips + one 13.5-in strip. Each 17-in strip = 1 top + 1 shelf + 1 side. The 13.5-in strips give all dividers. Shared assembly reference

Both sizes build with the identical 10-step sequence — cut & label, fill & sand edges, shelf between sides, rear bottom stretcher, dividers, rear top stretcher, 2×4 base, marry base to carcass, fasten top from inside, pads + finish. Step diagrams are in the two size guides. The only things that change between sizes are below.

Identical on every bench: side panels 14.25 × 17, top depth 17, height 18.5, base inset 1.5 all around, rear stretchers 3 in tall, butt joints with glue + screws, top fastened mechanically from inside.

SAFETY, all sizes: fasten every top with screws from inside (not brads/glue alone) — it is the lifting handle. Stack like-with-like; a mixed 3-and-4 stack loses the self-centering recess, so put the wider bench on the bottom and strap it. Don't stack more than 3 high unless wall-strapped. All benches are two-person lifts.

Build order at a glance

  • Buy Phase 1 now: 4 sheets plywood, 3 new 2×4 (+ 8 on-hand offcuts), glue, screws, pads.
  • Prototype: build one 3-ft bench completely, then dry-stack two and set them side by side before batching. Confirm flush + nesting.
  • Batch Phase 1: cut all 3-ft parts (S1–S4), then assemble the remaining five.
  • Buy Phase 2: 4 sheets plywood, 6 × 2×4.
  • Batch Phase 2: one sheet per 4-ft bench (S5–S8); use the 11-1/16 spacer for cubbies.
  • Final check: line all ten up in the intended run — tops and depths should align with no gaps.
