# Stackable Modular Cubby Benches (2026)

Ten backless cubby benches — six 3-ft and four 4-ft — sharing a 17 × 18.5 in
section with zero overhang so they sit flush in runs and stack via recessed
2×4 bases. **Status: Phase 1 (3-ft ×6) in progress.**
